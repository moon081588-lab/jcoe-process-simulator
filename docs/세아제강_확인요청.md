## ① 확관 #2호기 길이 상한 — 12.8m 인가 12.8384m 인가 ★최우선

| 자료 | 내용 |
|---|---|
| 공정 다이어그램 (슬라이드 3) | "12.8M~14M 제품 Only #1 Expander 가동" |
| 확관기별 공정 제약 (슬라이드 4) | "확관 2호기 — 12.8m **이상** 작업 불가" |
| 확관 최적화 운영 모델 | `elif length > 12.8384: m1_jobs` — 12.8384m **초과**부터 #1호기 전용 |

**왜 중요한가** — 현재 오더셋 물량의 **66%가 12.802m** 입니다.
12.8m 기준이면 이 물량 전체가 #1호기 전용이고, 12.8384m 기준이면 두 호기 다 가능합니다.

| 구분 (본, 총 1,446) | 12.8m 기준 | 12.8384m 기준 |
|---|---:|---:|
| #1호기 전용 | **960** | 0 |
| 두 호기 다 가능 (배분 규칙 대상) | 111 | **941** |
| #1호기 / #2호기 가동률 | **64% / 27%** | 41% / 43% |

12.8m 기준에서는 "호기 부하 편중은 배분 규칙이 아니라 제품 길이 구성에서 나온다"가 결론이고,
12.8384m 기준에서는 편중이 사라지고 배분 규칙·최적화가 손댈 수 있는 물량이 8배 커집니다.

**질문**
- 12.802m(42ft) 제품을 실제로 **#2호기에서 작업한 실적이 있습니까?**
- 있다면 제약표의 "12.8m 이상 불가"는 반올림 표기이고 실제 상한은 12.8384m 인가요?
- 없다면 운영 모델의 12.8384 임계값은 어디서 나온 값인가요?

## ② 확관 횟수 N 산출식 — 홀수인가 짝수인가, #1호기 식은 어느 쪽인가

| | #1호기 | #2호기 |
|---|---|---|
| 「JCOE 공정 생산 표준 시간 분석」 | `N = ceil((L−500)/step) + 2`, 짝수면 +1 → **항상 홀수** | 동일 |
| 확관 최적화 운영 모델 `specs.py` | `N = round(L / (step − (step≤150 ? 100 : 150)))` | `ceil((L−500)/step)+2`, **홀수면 +1 → 짝수** |

엑셀 주석은 "α를 제외한 N(확관 횟수) 계산 값이 짝수일 시 +1, 즉 N의 값은 항상 홀수",
운영 모델 `calculate_time_m2` 는 `if n_val % 2: n_val += 1` — **정확히 반대**입니다.

#1호기 식은 형태 자체가 달라, step 이 작을수록 격차가 폭발합니다.

| L(mm) | step(mm) | N(엑셀) | N(운영모델) | #1호기 시간 차 |
|---:|---:|---:|---:|---:|
| 12,802 | 700 | 21 | 23 | +5% |
| 12,802 | 460 | 29 | 41 | +25% |
| 12,802 | 300 | 45 | 85 | +62% |
| 12,000 | 110 | 107 | 1,200 | +867% |

전체 소요일도 **28.4일 → 32.3일(+14%)** 로 바뀌고, 확관이 포장과 공동 1위 병목으로 올라옵니다.

**질문**
- N 은 홀수여야 합니까, 짝수여야 합니까? (다이 왕복 특성상 어느 쪽이 물리적으로 맞는지)
- #1호기의 `step − 100 / step − 150` 은 다이 겹침(overlap) 보정입니까?
  그렇다면 엑셀 산출식의 `(L−500)/step + 2` 와 어떻게 연결됩니까?

## ③ RB 라인(= 확관 3호기) 투입 조건 — 외경 24" 이하인가 48"까지인가

| 자료 | 내용 |
|---|---|
| 공정 다이어그램 (슬라이드 3) | "RB 라인 투입 조건 (전부 만족): 두께 25T 이하 · 외경 **24" 이하**" |
| 운영 모델 `die_specs_rb` | Drawbar #600 → OD 610·660·711 / Drawbar #800 → OD 762~**1219**(48") |
| 운영 모델 `job_creator.py` | RB 다이표에 외경 존재 & **9 ≤ t ≤ 25.4** & L ≤ 12.8 |

다이어그램은 24"(610mm) 이하, 다이 스펙표는 24"~48" 를 커버합니다. 두께 하한(9mm)도
다이어그램에는 없습니다. 이 차이로 RB 통과 물량이 **25본 ↔ 93본**으로 달라집니다.

**질문**
- RB 라인의 실제 외경 범위는 어디까지입니까?
- 두께 하한 9mm 조건이 실제로 있습니까?

**아울러 확인 부탁** — 제약표의 "확관 3호기"가 RB 라인과 같은 설비로 이해했습니다.
근거는 "확관 3호기: 열처리 공정 제품 & 배척 제품 우선 투입"이 운영 모델의
`Force_RB`(병목공정 `HT102` = 열처리 / 원재료·제품 길이비 ≥ 1.8 = 배척)와 정확히 대응한다는 점입니다.
**확관 3호기 = RB 라인이 맞습니까?**

## ⑥ 병렬 설비 대수 — 자료에 없어 추정한 항목

시뮬레이터가 가정한 값입니다. 틀리면 병목 순위가 바뀝니다.

| 설비 | 현재 가정 | 확인 필요 |
|---|---:|---|
| 내면 SAW / 외면 SAW | 각 4라인 | 다이어그램 "4개 라인 병렬 운영" 근거 — 맞습니까? |
| **슬러그 제거** | **1대** | 4라인 병렬 안에 포함입니까, 단독 1대입니까? (가동률 70%, 2위 병목) |
| **포장 및 출하** | **1라인** | 몇 라인입니까? (가동률 85%, **1위 병목**) |
| 관단 X-ray | 1대 | |
| F-X ray | 2대 | 다이어그램 "Max 3대" — 상시 몇 대 가동입니까? |
| 면취기 / 수압 / CP | 각 1대 | |

민감도 분석 결과 — 슬러그 4라인 + 포장 2라인이면 전체 소요가 28.5일 → 27.1일이 되고
**확관이 1위 병목으로 올라옵니다.** 이 두 설비의 대수가 "확관이 병목"이라는 명제의 성립 여부를
좌우합니다.
