② 데이터 해석 규칙

qty_delta 는 신뢰할 수 없습니다자세히
PROD_QTY_cum 은 (설비 · WO · 작업일 · 근무조) 단위로 리셋됩니다 — 전체 파일 누적으로 읽으면 안 됩니다.
qty_delta 는 신뢰할 수 없습니다 — 직전 스냅샷을 놓친 구간에서 delta = cum 으로 찍힙니다 (예: cum 31 → delta 31). 그래서 본수는 교대별 최대 누적의 합으로 셉니다.
오더별 착수 시각은 없습니다 — LAST_TIME(마지막 완료 시각)만 있으므로, 검증은 완료 간격(본당 소요시간) 대 표준시간 산출식으로 합니다.

표준시간보다 큰 것이 정상자세히
실적 간격에는 대기·전환·정지가 모두 섞여 있어 표준시간보다 큰 것이 정상입니다. 실적 본당은 처리량 기준(ΣΔt ÷ ΣΔ누적)입니다. 스냅샷 한 간격이 여러 본을 담을 수 있어 누적 증가분으로 나눠서 환산합니다. 페이스는 그 값의 중위수로, 돌고 있을 때의 속도만 봅니다. 표준시간과의 비교에는 페이스가 아니라 실적 본당을 쓰십시오 — 페이스는 대기를 통째로 버리기 때문에 표준보다 빨라 보이는 착시가 생깁니다(2026-08-14 이 착시로 「포장 산출식이 65% 느리다」고 잘못 보고했습니다). 여유율이 0 에 가까울수록 쉬지 않고 돌고 있다는 뜻이라 진짜 병목입니다.
한 방향(하향)으로만 보정합니다. 실적 > 표준인 공정은 대기 때문인지 산출식 때문인지 구분할 수 없어 손대지 않습니다. 2026-08-14 실적 기준으로는 보정 대상이 하나도 없습니다 — 전 공정에서 실적 ≥ 표준입니다.

「계획서 시트 순서대로」는 조관계획서 JCOE 시트에 적힌 행 순서 그대로 시작일부터 흘려보냅니다 — 날짜·납기를 쓰지 않고 라인 자체의 처리 능력만으로 어떤 흐름이 나오는지 봅니다 (2026-08-14 세아제강 요청). 납기 지연 분석은 기본 해제입니다 — 영업계획납기일이 계획 시작일보다 과거인 행이 많아 지표가 의미를 잃습니다.

③ 시뮬레이션 파라미터

교대 시간대는 세아제강 실제 시간표 — 각 7.5h, 기본 2근자세히
1근 07:00–11:30 · 12:00–15:00 / 2근 15:00–18:00 · 18:30–23:00 / 3근 23:00–02:45 · 03:15–07:00. 각 7.5h. 2근연장은 2근에 23:30–03:00(+3.5h)이 붙습니다. 근무 형태가 월마다 달라 2근을 기본으로 봅니다.
「실가동 h/Shift」를 7.5 에서 바꾸면 하루 가동창 전체가 그 비율로 늘거나 줄어듭니다(민감도 분석용).
모델 구조자세히
모델 구조 — 파이프 1본 단위 FIFO 디스패치 시뮬레이션.
· 라우팅: 길이 > 13m → 18M 라인 / 이하 → 12M 라인. 두께 25T 초과 → Gap Press 투입. 단일 오더 API 5L 또는 50PCS 이상 → 1차 U.T, 그 외 By-pass.
· 확관: 적격 호기 중 배분 규칙에 따라 배정. 길이·외경 제약과 RB 투입 조건은 「확관 최적화」 탭의 확관 제약 기준을 따릅니다.
· 교대: Shift당 실가동 7.5H 기준 가동 시간대에만 작업이 진행되며, 비가동 시간대는 작업이 중단·이월됩니다.
· 전환시간: 확관 외 설비는 직전 처리 제품과 외경/두께/길이가 다를 때 설비별 툴·다이·클램프 교체 시간을 부가합니다.
· 확관 셋업(공구 계층): 호기별 다이 스펙표에서 장착 공구를 판정해 드로바 교체 270분 > 헤드 교체 150분 > 다이 교체 90분 > 동일 0을 적용합니다. (확관 최적화 운영 모델 산출 근거)
· API 5L: 조관계획서에 재질·규격 열이 없어 수량 50본 이상을 API 5L 대리변수로 씁니다. 다이어그램에서 1차 U.T 는 「API 5L 또는 50PCS 이상」, Final U.T·관단 X-ray 는 「API 5L」로 조건이 다릅니다 — 대리변수를 쓰면 두 조건이 같아지므로, 끄면 Final U.T·관단 X-ray 물량이 0 이 됩니다. (세아제강 확인 항목)
· 확관 N: 운영 최적화 모델(specs.py) 산출식이 기본값입니다 — #1호기 round(L / (step−150)), #2호기 ceil((L−500)/step)+2(짝수 보정). 「표준시간 분석」 엑셀 산출식(N 홀수)과는 결과가 다르며, 대조용으로 전환해 볼 수 있습니다.
