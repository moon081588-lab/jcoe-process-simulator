조관계획서 한 장으로 끝까지 — 업로드 → 최적화 → 시뮬레이션

“최적화 엔진을 한 번 돌리고 거기서 나온 스케줄대로 시뮬레이션에 흘러가게끔 하면 되려나” — 문세희
“다른 조관계획서 있으면 파일 업로드 하는 과정 추가해서 다른 계획서에도 흘러볼 수 있게” — 김명건
현재 계획서 · 현재 제약으로 최적화 엔진을 돌리고, 그 스케줄 그대로 시뮬레이션합니다.

1단계 · 조관계획서 불러오기 건너뛰면 기본 데이터(2026-03 포항공장)로 진행합니다

현재 기본 데이터는 2026년 3월 포항공장 조관계획서 기준 58오더 / 1,446본입니다. 다른 계획서를 넣으면 공정 흐름·간트·병목·In/Out·최적화가 모두 새 데이터로 다시 계산됩니다. 필요한 열은 외경 · 두께 · 길이 · 수량 네 가지이며, 오더번호·계획 투입일·납기·병목 공정 작업장·원재료내역은 있으면 함께 읽습니다.

2단계 · 조건 확인 기본값은 운영 모델 specs.py 기준입니다

3단계 · 최적화 엔진 실행 z(j,m) 호기 배정 + x(i,j) 투입 순서

③ 시뮬레이션 파라미터

모델 구조 — 파이프 1본 단위 FIFO 디스패치 시뮬레이션.
· 라우팅: 길이 > 13m → 18M 라인 / 이하 → 12M 라인. 두께 25T 초과 → Gap Press 투입. 단일 오더 API 5L 또는 50PCS 이상 → 1차 U.T, 그 외 By-pass.
· 확관: 적격 호기 중 배분 규칙에 따라 배정. 길이·외경 제약과 RB 투입 조건은 「확관 최적화」 탭의 확관 제약 기준을 따릅니다.
· 교대: Shift당 실가동 7.5H 기준 가동 시간대에만 작업이 진행되며, 비가동 시간대는 작업이 중단·이월됩니다.
· 전환시간: 확관 외 설비는 직전 처리 제품과 외경/두께/길이가 다를 때 설비별 툴·다이·클램프 교체 시간을 부가합니다.
· 확관 셋업(공구 계층): 호기별 다이 스펙표에서 장착 공구를 판정해 드로바 교체 270분 > 헤드 교체 150분 > 다이 교체 90분 > 동일 0을 적용합니다. (확관 최적화 운영 모델 산출 근거)
· API 5L: 조관계획서에 재질·규격 열이 없어 수량 50본 이상을 API 5L 대리변수로 씁니다. 다이어그램에서 1차 U.T 는 「API 5L 또는 50PCS 이상」, Final U.T·관단 X-ray 는 「API 5L」로 조건이 다릅니다 — 대리변수를 쓰면 두 조건이 같아지므로, 끄면 Final U.T·관단 X-ray 물량이 0 이 됩니다. (세아제강 확인 항목)
· 확관 N: 운영 최적화 모델(specs.py) 산출식이 기본값입니다 — #1호기 round(L / (step−150)), #2호기 ceil((L−500)/step)+2(짝수 보정). 「표준시간 분석」 엑셀 산출식(N 홀수)과는 결과가 다르며, 대조용으로 전환해 볼 수 있습니다.
